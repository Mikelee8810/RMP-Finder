# Install RMP Finder on Android

RMP Finder 1.0.0 is available as a personal sideload APK from GitHub Releases.

## Install from GitHub

1. Open <https://github.com/Mikelee8810/RMP-Finder/releases/latest> on the Android phone.
2. Under **Assets**, download `RMP-Finder-1.0.0.apk`.
3. Open the downloaded APK.
4. If Android asks for permission to install unknown apps, open **Settings**, enable **Allow from this source** for the app that opened the APK, then go back.
5. Tap **Install**.
6. Tap **Open**.

The app should open directly to the bundled 241-location RMP directory. Network access is not required for the directory, search, filters, favorites, or details.

## Build/install verification

The APK published for 1.0.0 is Android v2-signed and was installed successfully on a Pixel 10 Pro XL running Android 17. The installed app launched successfully and displayed `241 of 241 RMP locations`.

The v1 acceptance evidence is recorded in [android-v1-acceptance.md](android-v1-acceptance.md).
