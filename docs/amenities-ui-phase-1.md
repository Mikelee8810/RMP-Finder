# Amenities UI — Phase 1 Visual Lock

Status: APPROVED DESIGN CHECKPOINT

This phase locks the visual direction for the redesigned “At this location” section before any production icon or UI code is changed.

## Approved layout

The section remains inside the existing white rounded card.

### Essentials
- Dine-in
- Restroom
- Two compact items side by side

### Meals
- Breakfast
- Lunch
- Dinner
- Three compact items in one row when space allows; wrap cleanly on smaller screens

### Wheelchair access
- Entrance
- Restroom
- Seating
- Parking
- Compact 2 × 2 layout

## Icon direction

Use a custom RMP Finder icon family, not generic system icons or emoji.

- Warm cream backing shapes
- Dark charcoal linework
- Warm orange/red accent
- Rounded, friendly geometry
- Small visual footprint so icons support the text instead of dominating it
- Consistent size and weight across all nine icons

Required icons:
1. Dine-in
2. Restroom
3. Breakfast
4. Lunch
5. Dinner
6. Accessible entrance
7. Accessible restroom
8. Accessible seating
9. Accessible parking

## Status treatment

- Yes: small green check/status treatment
- No: muted gray status treatment
- Unknown: neutral/muted treatment or omitted when the layout would become noisy

Status should be readable without making the card look like a wall of badges.

## Size and spacing

The smaller-icon mockup is the approved reference.

- Icons are intentionally smaller than the first mockup
- Labels remain more visually important than the icons
- Keep generous breathing room inside each compact item
- Preserve the current card padding and rounded visual language
- Do not make the “At this location” card taller than necessary

## Scope lock

Phase 1 changes design documentation only.

Do not change:
- restaurant data
- Notion structure
- Google Places data
- hours card
- restaurant header
- action buttons
- navigation
- any other screen

## Phase 2 handoff

Phase 2 may create the nine production Android icon assets using this document as the visual contract. It must not redesign the layout or touch unrelated app code.
